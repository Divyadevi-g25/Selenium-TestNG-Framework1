# Selenium TestNG Automation Framework (OrangeHRM)

## Project Overview
This project is a **Test Automation Framework** built using Selenium WebDriver, TestNG, and Maven to automate the OrangeHRM web application.

It demonstrates end-to-end automation of key HR functionalities with a scalable and maintainable framework design.

---

## 🧰 Tech Stack
- Java
- Selenium WebDriver
- TestNG
- Maven
- Git
- Jenkins (CI/CD)

---

## Framework Design
- Page Object Model (POM)
- Data-Driven Testing
- Reusable utility functions
- TestNG annotations & execution control

## Features
- Automated Login, PIM, Leave, Admin modules
- Cross-browser testing support
- Parallel execution using TestNG
- HTML/Extent Reports generation
- CI/CD integration using Jenkins

## How to Run the Project

### 1. Clone the Repository

git clone https://github.com/Divyadevi-g25/Selenium-TestNG-Framework1.git

### 2. Navigate to Project

cd Selenium-TestNG-Framework1

### 3. Run Tests using Maven

mvn clean test
